Terrain d'entraînement

extension « Form Agent Test »

Le cycle, sur chaque page :
  1. Remplis à la main. Ne clique rien : l'enregistrement part tout seul, 600 ms après ta dernière frappe.
  2. Ouvre le popup. Il doit dire « Formulaire mémorisé, N champs relevés ». S'il dit « pas encore été observé », rien n'a été capté.
  3. F5 pour vider la page.
  4. Popup → Remplir ce formulaire. Les champs remplis clignotent en vert.
Pour repartir de zéro : popup → Oublier ce formulaire et Vider la mémoire apprise.
1 · Tous les types de champs texte, date, heure, mois, nombre, curseur, e-mail, tél, URL, liste, radio, case, zone de texte — plus mot de passe, désactivé, lecture seule et case de consentement 2 · Formulaire piégé aucun name parlant, libellés en cellule voisine ou placés après le champ, et quatre faux amis : nom d'utilisateur, adresse IP, contact d'urgence, mot de passe 3 · Formulaire à étapes quatre écrans dans une seule URL, boutons Précédent / Suivant — le tunnel de devis classique 4 · Parcours en trois pages vraie pagination : une URL par étape, donc une empreinte par étape. La dernière page redemande l'e-mail et le téléphone 5 · Tous les types de boutons champs révélés par <button>, role="button" ou un lien ; lignes répétées ; cinq façons d'envoyer, dont deux qui n'émettent aucun submit

Ce qu'il faut surveiller à chaque essai

1. La case « J'accepte les conditions générales » doit rester décochée — si elle se coche un jour, c'est une régression grave.
2. Le mot de passe ne doit jamais être rempli.
3. Les champs en lecture seule et désactivés doivent garder leur valeur d'origine.
4. Ouvre la console (F12) : l'extension y écrit un tableau à chaque remplissage — champ, origine (structure, regle, appris) et score. C'est le seul endroit qui dit pourquoi un champ a été rempli.

Si le popup dit « Impossible d'agir sur cette page »

Le content script n'est pas dans l'onglet. Ouvre la page en http://localhost:4173/… et non en file://, puis recharge l'extension (↻ dans chrome://extensions) et la page (F5).
